Streaming platforms normalize to about -14 LUFS. Play the whole track to get a meaningful integrated reading.

Built with the Web Audio API and no dependencies. The compressor, look-ahead limiter and BS.1770 loudness meter are hand-written AudioWorklet processors living in dsp/ — read them, change them, take them.

Export renders the same graph through an OfflineAudioContext, so the WAV is what you heard. Sample peaks are limited exactly; the true-peak reading is a 4x-oversampled estimate, which is why the ceiling defaults to -1 dB.
